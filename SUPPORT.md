# Support

## Before asking for help

1. Read `README.md`, `INSTALL.md`, and `TROUBLESHOOTING.md`.
2. Run:

```bash
npm run verify
npm audit
npm run doctor
```

3. Remove Discord tokens, credentials, private user data, and other secrets from logs before sharing them.

## Bug reports

Use GitHub Issues and choose the bug report template. Include:

- Bot version
- Node.js version
- Operating system
- Relevant configuration names without secret values
- Reproduction steps
- Sanitized logs

## Feature requests

Use the feature request template and describe the problem first, then the proposed behavior.

## Security issues

Do not open a public issue for vulnerabilities, leaked credentials, token exposure, or other security-sensitive reports. Follow `SECURITY.md`.

## Scope

This is a self-hosted project. Server administration, Discord account issues, hosting-provider problems, and unrelated third-party service outages are outside the project's support scope unless they expose a reproducible bug in this repository.
