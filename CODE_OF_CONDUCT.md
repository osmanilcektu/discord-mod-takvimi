# Code of Conduct

## Our commitment

We want this project to be a welcoming, professional, and constructive place for users and contributors.

Participants are expected to communicate respectfully, focus on technical issues and project goals, and avoid harassment, discrimination, threats, personal attacks, spam, or deliberately disruptive behavior.

## Expected behavior

- Be respectful and constructive in issues, pull requests, and discussions.
- Assume good intent and keep feedback focused on the work.
- Respect privacy and never publish another person's credentials, tokens, logs containing secrets, or private data.
- Report security-sensitive problems privately according to `SECURITY.md` instead of opening a public issue.
- Follow the repository's contribution and testing requirements.

## Unacceptable behavior

Examples include harassment, discriminatory language, personal attacks, publishing private information without permission, intentionally misleading security reports, spam, and repeated disruption after maintainer guidance.

## Enforcement

Project maintainers may edit, hide, lock, or remove content and may restrict participation when necessary to protect the project and its community.

For security issues, follow `SECURITY.md`. For ordinary project questions, use GitHub Issues.

## Scope

This Code of Conduct applies to all project spaces maintained under this repository.
